## 💻 程式碼風格規範

以下規範適用於本專案中所有 Python 程式碼範例：

### 命名規則
- 變數名稱、函式名稱：使用 **snake_case**（小寫加底線）
  - ✅ 正確：`student_name`、`calculate_bmi`
  - ❌ 錯誤：`studentName`、`CalculateBmi`
- 常數：使用 **全大寫加底線**
  - ✅ 正確：`MAX_SCORE`、`PI_VALUE`
- 類別名稱：使用 **PascalCase**
  - ✅ 正確：`StudentRecord`、`DataProcessor`

### 縮排規則
- 統一使用 **4 個空格**縮排，禁止使用 Tab 鍵
- VS Code 設定：`"editor.tabSize": 4`、`"editor.insertSpaces": true`

### 註解語言
- 程式碼內的**行內註解**與**說明文件（docstring）**一律使用**繁體中文**
- 範例：

```python
def calculate_bmi(weight, height):
    """
    計算 BMI 值（身體質量指數）
    
    參數：
        weight (float): 體重，單位為公斤
        height (float): 身高，單位為公尺
    
    回傳：
        float: BMI 數值，四捨五入至小數點後兩位
    """
    bmi = weight / (height ** 2)  # BMI 公式：體重 / 身高的平方
    return round(bmi, 2)
```
